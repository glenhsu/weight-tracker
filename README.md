# 💪 我獨自升級 V1.0 — 健身訓練追蹤器

> **資料只存手機，不註冊、不上傳、不用網路。**  
> 打開瀏覽器就能用，關掉 App 資料也不會消失。

---

## 為什麼你需要這個？

大多數健身 App 都要你註冊帳號、上傳資料到雲端、看廣告、買會員。  
「我獨自升級」反過來——**你的資料永遠只在你手機裡**，沒有伺服器、沒有後台、沒有人能偷看你的訓練紀錄。

## 功能一覽

| 功能 | 說明 |
|------|------|
| 🏋️ **訓練範本** | 建立自己的訓練課表，運動項目分欄位輸入（動作名、次數、重量），可新增/刪除/編輯/存檔 |
| ▶️ **開始訓練** | 按範本展開訓練，每組可標記完成，自動計算 1RM |
| ⏱ **休息倒數** | 內建計時器，最後 3 秒逼聲提醒，結束時響鈴通知 |
| 📊 **PR 排行榜** | 自動計算每項動作的最佳 1RM 紀錄，刪除訓練後自動同步 |
| 📋 **訓練紀錄** | 完整歷史紀錄，可按日期檢視，錯誤訓練一鍵刪除 |
| ⚙️ **設定** | 自訂休息秒數，深色主題介面 |

## 快速開始

1. 用手機 Chrome / Safari 打開 `index_v6.html`
2. 新增一個訓練範本（例如：胸日）
3. 加入動作（例如：臥推 60kg×10、上斜啞鈴 20kg×12）
4. 點「開始訓練」開練！
5. 做完按「完成組數」，休息倒數自動開始

> 💡 **小技巧**：iOS 用戶可以用 Safari 的「加入主畫面」把它變成獨立 App 圖示，開啟後全螢幕無網址列干擾。

## 技術亮點

- **單頁 HTML** — 一個檔案搞定，沒有框架、沒有後端、沒有第三方依賴
- **localStorage 儲存** — 資料全存在手機本地，刪除 App 前記得備份
- **Web Audio API 提示音** — 不用下載音檔，瀏覽器原生音效
- **全端計算** — 1RM 公式：`重量 × (1 + 次數 / 30)`
- **手機自適應** — 自動填滿螢幕、隱藏網址列、支援旋轉

## 隱私承諾

```
✅ 零後端伺服器
✅ 零帳號註冊
✅ 零資料上傳
✅ 零廣告
✅ 零追蹤器
❌ 不蒐集任何資料
```

你的訓練紀錄只在你手機的 localStorage 裡，連開發者都看不到。

## 適合誰？

- 不想讓健身 App 知道你的體能數據的隱私控
- 不想每個月付訂閱費的務實派
- 只需要一個計組數計時器的純粹主義者
- 想在 iPhone/Android 上無痛同步的玩家（把 HTML 放到 iCloud/Google Drive 即可兩邊存取）

## 自行備份

因為資料只存手機，建議定期備份：

```
打開 Chrome DevTools → Application → Local Storage → gym_v5_db
全選複製 → 貼到記事本 → 存檔
```

或直接從瀏覽器將整個 `index_v6.html` 複製到雲端硬碟。
